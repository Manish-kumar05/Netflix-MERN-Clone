# Netflix MERN Clone

A full-stack Netflix-inspired movie streaming web application built using the MERN stack.

## Features

- User Authentication (JWT)
- Login & Register System
- Trending Movies
- Movie Search
- Watchlist / My List
- Movie Details Popup
- Hero Banner
- Responsive UI
- Tailwind CSS Styling
- TMDB API Integration

## Tech Stack

### Frontend
- React.js
- React Router DOM
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Mongoose

## API Used

- TMDB (The Movie Database) API
